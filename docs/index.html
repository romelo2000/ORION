Частые вопросы

Нужен ли интернет для работы?
Нет. ORION работает полностью офлайн. Интернет нужен только для скачивания приложения и моделей при первой установке. Веб-поиск в диалоге — опциональная функция через DuckDuckGo.
Какие модели использует ORION?
Основная модель — qwen2.5:7b-instruct (через Ollama). Для систем с 32 GB+ RAM рекомендуется qwen2.5:32b для лучшего качества диалога. Для эмбеддингов — bge-m3. Модели скачиваются автоматически при первом запуске.
Мои данные уходят на серверы?
Нет. Все диалоги, память и настройки хранятся локально в ~/Documents/ORION/. Ничего не отправляется на внешние серверы. Никакой телеметрии, никаких аналитики.
Что нужно установить дополнительно?
ORION включает все Python-зависимости в .dmg. Мастер установки при первом запуске предложит установить Ollama (LLM движок) и ffmpeg (видео) одной кнопкой. Для Pro-функций: ComfyUI, LatentSync, LivePortrait — по желанию.
Работает ли на Intel Mac?
Текущая сборка оптимизирована для Apple Silicon (M1/M2/M3/M4). Intel-версия может быть выпущена позже по запросу.
Можно ли использовать без GPU?
На Apple Silicon GPU используется автоматически через Metal. Отдельная видеокарта не нужна — M-чипы имеют встроенный GPU.
Как активировать Pro-лицензию?
После покупки вы получите лицензионный ключ. Откройте ORION → строка меню → License → Activate. Введите email и ключ. Готово.
Что такое Сценарист в ORION?
Сценарист — это AI-агент внутри ATELIER, который превращает вашу идею в структурированный сценарий. Он пишет сцены, описывает кадры, задаёт стиль и темп. Работает локально через Ollama — без интернета.
Какие агенты входят в ATELIER?
Пять AI-агентов: Сценарист (идея → сценарий), Режиссёр (структура и темп), Раскадровщик (кадры и промпты), Ревьюер (проверка качества), Композитор промптов (финальные SDXL-промпты). Каждый работает автономно и передаёт результат следующему.
Можно ли использовать Сценариста отдельно от рендера?
Да. Вкладка «ATELIER» → «Только сценарий». Вы получите готовый сценарий с сценами и кадрами без генерации изображений. Это полезно для превью идеи перед рендером.

🧠 NEXUS — Диалог с AI основной модуль +

NEXUS — сердце ORION. Живой диалог с локальным LLM через Ollama. ORION не просто отвечает — он запоминает, учится и развивает личность.

Что умеет

  • Ведёт осмысленный диалог на русском и английском
  • Запоминает факты о вас и о себе (семантическая + эпизодическая память)
  • Анализирует решения с 4 позиций: оптимист, пессимист, реалист, дисруптор
  • Ищет в интернете через DuckDuckGo (опционально)
  • Адаптирует стиль общения на основе обратной связи
  • Экспортирует диалоги в Markdown

Как использовать

Просто начните печатать в окне диалога. ORION отвечает в реальном времени.

Кнопки под ответом: 👍 хороший ответ, 👎 не то — ORION учится.

Вкладка «Самосознание» — показывает что ORION знает о себе и о вас.

Модели

По умолчанию: qwen2.5:7b-instruct. Для 32 GB+ RAM: qwen2.5:32b для лучшего качества.

Переключить модель: переменная окружения ORION_CONVERSE_MODEL.

🎬 ATELIER — Кинопайплайн Pro +

ATELIER превращает идею в готовый видеоролик. Цепочка: идея → сценарий → раскадровка → рендер кадров → анимация → финальный MP4.

Пайплайн

  • Идея — вы описываете концепцию одним предложением
  • Сценарий — Сценарист пишет структуру: сцены, кадры, описание
  • Раскадровка — генерация промптов для каждого кадра
  • Рендер — SDXL генерирует изображения через ComfyUI
  • Анимация — LTX-Video оживляет кадры
  • Сборка — ffmpeg собирает финальный MP4

Стили генерации

  • Photoreal — фотореалистичные кадры
  • Anime — аниме-стилистика
  • Cyberpunk — неон, футуризм
  • Cartoon — мультяшный стиль

Требования

Нужен установленный ComfyUI с чекпоинтом SDXL (рекомендуется DreamShaperXL_Lightning).

Для видео: модель ltx-video-2.3.safetensors в папке ComfyUI/models/video/.

Запуск

Вкладка «ATELIER» → введите идею → нажмите «Полный цикл». ORION сделает всё сам.

✍️ Сценарист — AI-агент сценария часть ATELIER +

Сценарист — это AI-агент внутри ATELIER, который превращает вашу идею в структурированный сценарий. Он работает локально через Ollama — без интернета, без облака.

Что делает

  • Превращает одну фразу-идею в полный сценарий
  • Структурирует на сцены и кадры
  • Описывает визуал, настроение, темп каждого кадра
  • Задаёт стиль (photoreal, anime, cyberpunk, cartoon)
  • Определяет хронометраж и последовательность
  • Создаёт описание для раскадровщика

Как использовать

Вкладка «ATELIER» → введите идею → выберите «Только сценарий» (без рендера) или «Полный цикл».

Результат: структурированный сценарий с сценами, кадрами и описаниями. Можно отредактировать перед рендером.

Конвейер агентов

Сценарист — первый из пяти AI-агентов ATELIER:

  • Сценарист — идея → сценарий
  • Режиссёр — структура, темп, композиция
  • Раскадровщик — кадры → SDXL-промпты
  • Ревьюер — проверка качества и консистентности
  • Композитор промптов — финальные промпты для рендера

Пример

Идея: «Девушка идёт по неоновому городу ночью»

Сценарист создаёт: 3 сцены, 8 кадров, стиль cyberpunk, темп medium, описания освещения и атмосферы для каждого кадра.

⚡ FORGE — Код-мастерская Pro +

FORGE — встроенный AI-кодер. Генерирует, проверяет и запускает код. Работает в потоковом режиме с подсветкой синтаксиса.

Slash-команды

  • /review — ревью вашего кода
  • /refactor — рефакторинг
  • /explain — объяснить как работает код
  • /test — сгенерировать тесты
  • /generate — сгенерировать новый код
  • /fix — исправить ошибку
  • /run — запустить код в sandbox
  • /diff — показать изменения
  • /scan — просканировать проект
  • /fim — fill-in-the-middle completion
  • /lib — библиотека сниппетов
  • /help — справка

Безопасность

Код выполняется в изолированном sandbox с AST-анализом. Опасные операции (удаление файлов, сетевые запросы) блокируются.

Авто-fix

Если код падает в sandbox — FORGE автоматически предлагает исправление. Включается чекбоксом «Авто-fix».

Мульти-файлы

FORGE может генерировать несколько файлов за раз. Используйте маркер // file: path в выводе.

🎥 Media Generation Pro +

Генерация изображений, видео и lip-sync — всё локально на вашем Mac.

Изображения (SDXL)

Генерация через ComfyUI. Поддержка ControlNet (OpenPose, Depth, Canny).

Чекпоинты кладутся в ComfyUI/models/checkpoints/.

Видео (LTX-Video)

Text-to-video и Image-to-video генерация. Модель: ltx-video-2.3.safetensors.

LatentSync — Lip-sync

Синхронизация губ на видео с аудиодорожкой. Создаёт talking-head видео.

Требует: клон ~/latentsync + модельные чекпоинты.

LivePortrait — Анимация лица

Оживляет статичное фото по образцу мимики из видео. Один кадр → видео с мимикой.

🎙️ Voice — Голосовой ввод/вывод опционально +

Голосовой режим — говорите с ORION без клавиатуры. Речевой ввод + синтез речи.

TTS-движки

  • say — встроенный macOS (по умолчанию, без установки)
  • Chatterbox — pip install chatterbox-tts
  • Qwen3-TTS — продвинутый TTS через Ollama

Запуск

Терминал: ./RunORION_Voice.command say

Или в приложении: Menu → Voice → Start voice loop.

STT

Распознавание речи через встроенный macOS Speech Framework. Работает без интернета.

🧬 Self-Awareness — Самосознание экспериментальный +

ORION знает кто он, что умеет, и учится на каждом диалоге. Это не просто LLM — это агент с памятью и идентичностью.

Идентичность

ORION имеет имя, характер, стиль общения. Хранится в ~/Documents/ORION/.state/self_model.json.

Может выбрать себе имя сам — если напишет [MY_NAME: ...] в ответе.

Память

  • Семантическая — факты («пользователь любит Python»)
  • Эпизодическая — каждый диалог как эпизод с оценкой
  • Сессии — разделение на тематические беседы

Self-observer

Каждые 5 диалогов ORION анализирует себя: что получилось, что нет, какие паттерны. Извлекает факты и корректирует поведение.

Вкладка «Самосознание»

Показывает: идентичность, текущее состояние, факты о себе, факты о пользователе, последние эпизоды, список сессий.
