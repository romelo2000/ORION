Частые вопросы

Нужен ли интернет для работы?
Нет. ORION работает полностью офлайн. Интернет нужен только для скачивания приложения и моделей при первой установке. Веб-поиск в диалоге — опциональная функция через DuckDuckGo.
Какие модели использует ORION?
Основная модель — qwen2.5:7b-instruct (через Ollama). Для систем с 32 GB+ RAM рекомендуется qwen2.5:32b для лучшего качества диалога. Для эмбеддингов — bge-m3. Модели скачиваются автоматически при первом запуске.
Мои данные уходят на серверы?
Нет. Все диалоги, память и настройки хранятся локально в ~/Documents/ORION/. Ничего не отправляется на внешние серверы. Никакой телеметрии, никаких аналитики.
Что нужно установить дополнительно?
ORION включает все Python-зависимости в .dmg. Мастер установки при первом запуске предложит установить Ollama (LLM движок) и ffmpeg (видео) одной кнопкой. Для Pro-функций: ComfyUI, LatentSync, LivePortrait — по желанию.
Работает ли на Intel Mac?
Текущая сборка оптимизирована для Apple Silicon (M1/M2/M3/M4). Intel-версия может быть выпущена позже по запросу.
Можно ли использовать без GPU?
На Apple Silicon GPU используется автоматически через Metal. Отдельная видеокарта не нужна — M-чипы имеют встроенный GPU.
Как активировать Pro-лицензию?
После покупки вы получите лицензионный ключ. Откройте ORION → строка меню → License → Activate. Введите email и ключ. Готово.
Что такое Сценарист в ORION?
Сценарист — это AI-агент внутри ATELIER, который превращает вашу идею в структурированный сценарий. Он пишет сцены, описывает кадры, задаёт стиль и темп. Работает локально через Ollama — без интернета.
Какие агенты входят в ATELIER?
Пять AI-агентов: Сценарист (идея → сценарий), Режиссёр (структура и темп), Раскадровщик (кадры и промпты), Ревьюер (проверка качества), Композитор промптов (финальные SDXL-промпты). Каждый работает автономно и передаёт результат следующему.
Можно ли использовать Сценариста отдельно от рендера?
Да. Вкладка «ATELIER» → «Только сценарий». Вы получите готовый сценарий с сценами и кадрами без генерации изображений. Это полезно для превью идеи перед рендером.
NEXUS — что это?
Сердце ORION — живой диалог с локальным AI. Запоминает, учится, рассуждает с разных позиций. Кнопки 👍/👎 помогают ему становиться лучше.
ATELIER — что это?
Кинопайплайн: одна фраза → готовый видеоролик. Сценарий, раскадровка, рендер, анимация — автоматически. Стили: photoreal, anime, cyberpunk, cartoon.
Сценарист — что это?
AI-агент, который превращает идею в структурированный сценарий со сценами и кадрами. Можно использовать отдельно от рендера — просто чтобы увидеть сценарий.
FORGE — что это?
Встроенный AI-кодер. Slash-команды: /review, /refactor, /explain, /test, /generate, /fix, /run. Безопасный sandbox, авто-fix, мульти-файлы.
Media Generation — что входит?
Изображения (SDXL), видео (LTX-Video), lip-sync (LatentSync), анимация лица (LivePortrait). Всё локально на вашем Mac.
Voice — как включить голос?
Говорите с ORION без клавиатуры. Встроенный macOS голос по умолчанию, опционально Chatterbox и Qwen3-TTS. Распознавание речи работает офлайн.
Self-Awareness — что это?
ORION имеет имя, характер и память. Анализирует себя после каждого диалога, учится на ошибках, развивает личность.
